데이터 집계 중

수치의 정본은 이 화면(Firestore)입니다. 구글 애널리틱스는 광고 차단기 사용자가 빠지므로 유입 경로 참고용으로만 보세요.
데이터 보호를 위해 초기화 기능은 제공하지 않습니다. 정적 페이지라 앱 안에 초기화를 두면 참여자도 실행할 수 있기 때문입니다. 초기화가 필요하면 Firebase 콘솔에서 games/{게임} 문서와 하위 shards, users 컬렉션을 직접 삭제하세요.
